# NewsRadar
📰 NewsRadar

NewsRadar is a Django-based news aggregation platform that provides the latest news updates in one place. Users can search and filter news by category, read full articles, register/login, bookmark favorite articles, and add comments.

🛠️ Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- RSS Feed

✨ Features

- Live news updates
- News search and category filtering
- User authentication
- Article details page
- Bookmark system
- Comment system
- User profile

🚀 Run the Project

python manage.py runserver

Open:

http://127.0.0.1:8000/

Developed as an academic project using Python and Django.
